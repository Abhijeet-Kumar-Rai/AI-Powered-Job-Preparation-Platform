# AI-Powered-Job-Preparation-Platform
Tech Stack: React.js, Node.js, Express.js, MongoDB, Gemini AI, JWT, Puppeteer
Developed a full-stack AI-powered job preparation platform that analyzes resumes and job descriptions to identify skill gaps and generate
personalized interview questions and preparation reports.
Implemented secure JWT authentication, protected routes, token blacklisting, resume uploads, and RESTful APIs for user and interview
report management.
Integrated Gemini AI for resume analysis, skill extraction, skill-gap detection, interview question generation, and ATS-optimized resume
creation.
Built an automated AI-to-PDF pipeline using Puppeteer to generate downloadable, professionally formatted resumes.
Developed the React frontend using React Router, Context API, custom hooks, Axios, and reusable components for authentication and report
management.
